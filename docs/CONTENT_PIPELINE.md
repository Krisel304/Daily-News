# 每日内容生产规范

## 1. 采集

优先级从高到低：

1. 官方公告、官方产品文档、论文；
2. 可信技术媒体或通讯；
3. 公司与核心研究者的一手社交账号；
4. 其他平台只作为发现线索，不作为唯一事实来源。

## 2. 验证

每条候选内容必须确认：

- 原始标题、原始链接和实际发布时间；
- 发布主体与内容是否一致；
- 摘要中的数字、版本、地区和开放范围；
- 信息是否处于指定采集时间窗口；
- 是否存在更新、撤回或与其他一手来源冲突。

## 3. 去重

以“同一事件”为单位合并跨平台内容。保留信息最完整、最接近事实源头的链接；其他帖子可作为热度或影响信号，但不重复生成新闻卡片。

## 4. 评分

重要度采用 1–5 星，内部权重为：

- 行业影响：35%
- AI 产品相关性：30%
- 新颖度：20%
- 来源可信度：15%

5 星应保留给会改变模型能力边界、产品范式、主要平台策略或监管环境的事件。

## 5. 输出

每条新闻保持统一字段：

- 标题；
- 来源平台与原始链接；
- 发布时间与主题；
- 1–5 星重要度；
- 一句话结论；
- 30 秒摘要；
- 为什么值得 AI 产品人关注。

摘要应解释核心变化，不重复标题，不加入来源无法支持的推断。产品解读可以包含判断，但必须与事实摘要明确区分。

## 6. 发布验收

发布前完成：

```bash
npm run lint
npm test
```

同时人工检查链接、移动端布局、当天日期、新闻数量、重复事件和空状态。
